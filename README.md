# BetterNameCommingSoon

![Language: C#](https://img.shields.io/badge/C%23-8A2BE2)
[![Made with Godot 4.7](https://img.shields.io/badge/Godot%204.7-478CBF?style=flat&logo=godot%20engine&logoColor=white)](https://godotengine.org)

{BetterNameCommingSoon} is a restaurant management and simulation game that combines realistic cooking mechanics with idle and management elements.

---

## Quick Setup

1. Install godot for your system:
   - Arch: `sudo pacman -S godot-mono`
   - App Image: [Godot 4 download](https://godotengine.org/download/linux/)

1. Clone the project `git clone git@github.com:Demon-God666/idlesim.git`
1. Open the project in godot | See: [Opening and importing projects in Godot](https://docs.godotengine.org/en/4.7/tutorials/editor/project_manager.html#opening-and-importing-projects)

## Naming convention

For commiting use: `IDS-XX: commit message`
IDS stands for IdleSim. XX is the ticket number.

Branches are called: `IDS-XX--my-feature` with xx beeing the ticket number.
